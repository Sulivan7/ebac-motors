# 🚗 EBAC Motors

Um site para uma loja de veículos de luxo, desenvolvido com HTML5, CSS3 e JavaScript.

### 🌐 Link do Projeto

**[Acesse o site ao vivo](https://ebac-motors-azure.vercel.app/)**

## 🚀 Funcionalidades

- ✨ **Carousel de imagens** com autoplay usando Slick Carousel
- 📝 **Formulário de contato** com validação completa
- 🎭 **Máscara de telefone** formatada automaticamente
- 📧 **Preenchimento automático** do veículo de interesse

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript/jQuery**
- **Slick Carousel**
- **jQuery Validate**
- **jQuery Mask**

### 📞 Contato

Formulário completo com:

- Nome (obrigatório)
- Telefone (obrigatório, com máscara)
- E-mail (obrigatório, com validação)
- Veículo de interesse (preenchido automaticamente)
- Mensagem (obrigatória)

## 🚀 Como Executar

1. **Clone o repositório**

   ```bash
   git clone https://github.com/Sulivan7/ebac-motors.git
   ```

2. **Navegue até o diretório**

   ```bash
   cd ebac-motors
   ```

3. **Abra o arquivo `index.html`**
   - Duplo clique no arquivo, ou
   - Use um servidor local como Live Server (VS Code)

### Validação de Formulário

- Campos obrigatórios marcados
- Validação de e-mail
- Mensagens em português
- Feedback visual para erros
